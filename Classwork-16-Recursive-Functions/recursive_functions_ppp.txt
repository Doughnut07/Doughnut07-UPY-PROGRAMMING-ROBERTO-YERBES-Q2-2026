FUNCION recursiva(n)

    Intentar

        Si n no es un entero Entonces
            Lanzar Error
        FinSi

        Si n < 0 Entonces
            Lanzar Error
        FinSi

        Si n = 0 Entonces
            Retornar "Done!"
        Sino
            Escribir n
            Retornar recursiva(n - 1)
        FinSi

    Capturar Error
        Escribir "Error en recursiva"

FUNCION aplanar_json(diccionario, clave_padre, separador)

    Intentar

        Si diccionario no es un diccionario Entonces
            Lanzar Error
        FinSi

        Crear lista elementos vacía

        Para cada llave y valor del diccionario

            Si clave_padre está vacía Entonces
                nueva_llave = llave
            Sino
                nueva_llave = clave_padre + separador + llave
            FinSi

            Si valor es un diccionario Entonces
                Agregar el resultado de
                aplanar_json(valor, nueva_llave, separador)
            Sino
                Agregar (nueva_llave, valor)
            FinSi

        FinPara

        Retornar elementos

    Capturar Error
        Escribir "Error en aplanar_json"
        Retornar Diccionario vacío
